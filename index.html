UNDER THE HOOD

How matching works

✳
Aa
Text extraction

Reads selectable text from PDF and DOCX resumes.

⌘
Text similarity

TF-IDF and cosine similarity compare job and resume wording.

✓
Skill comparison

Checks which listed skills appear in each resume.

SCORING FORMULA65% Text similarity + 35% Skill coverage

Used when a required-skill list is provided. Otherwise, the text similarity score is used.

ⓘ
Decision-support only

A match score is an estimate based on text. It is not a hiring decision and cannot measure a candidate's full ability or potential.
